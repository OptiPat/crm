Patrimoine CRM — feuille de route Tony

Informatique A · Comptes Microsoft

Centre d’admin : admin.microsoft.com

  1. Créer ou vérifier 1 compte par personne (prénom.nom du cabinet), pas une boîte partagée :
    • Tony — e-mail :                     
    • Assistante 1 — e-mail :                   
    • Assistante 2 — e-mail :                   
  2. Chaque compte a une licence avec SharePoint et messagerie.
  3. Activer le code à 2 facteurs (MFA) sur les 3 comptes.
  4. Chacun se connecte une fois sur portal.office.com et valide le code. ☐ fait

Informatique B · Groupes Entra (les rôles)

Entra admin → Identity → Groups → All groups

  1. Créer un groupe de sécurité CRM - Conseillers. Y mettre uniquement Tony.
  2. Ouvrir le groupe → copier l’Object ID (un long numéro) → le coller page 4.
  3. Créer un groupe de sécurité CRM - Assistantes. Y mettre uniquement les assistantes.
  4. Copier l’Object ID → le coller page 4.
  5. Vérifier : personne n’est dans les deux groupes. ☐ fait

Informatique C · Site SharePoint

  1. Créer un site rien que pour le CRM, par exemple :
    https://cabinet.sharepoint.com/sites/crm-patrimoine
  2. Tony = propriétaire du site. Les assistantes = membres.
  3. Noter (page 4) :
    • Hostname = la partie avant /sites/ (ex. cabinet.sharepoint.com)
    • Chemin = ce qui commence par /sites/…
  4. Les 3 personnes ouvrent l’URL du site dans le navigateur. Ça doit marcher. ☐ fait
  5. Ne créez aucune liste à la main. Tony le fera dans le CRM.

Suite page suivante : application Entra, autorisation du site, boîte cabinet.

Informatique D · Application Entra « Patrimoine CRM »

Entra admin → App registrations → New registration

  1. Nom : Patrimoine CRM. Comptes : cet annuaire uniquement.
  2. Authentication → Add a platform → Mobile and desktop applications.
  3. URI de redirection, exactement :
    http://127.0.0.1:3847/callback
  4. Autoriser les flux clients publics (Allow public client flows = Oui).
  5. API permissions → Microsoft Graph → Delegated, ajouter pile ceci :
    • User.Read
    • GroupMember.Read.All
    • Sites.Selected
    • Mail.Send.Shared
    • offline_access
    • openid
    • email
  6. Grant admin consent (bouton « Accorder le consentement administrateur »). ☐ fait
  7. Copier l’Application (client) ID → page 4. Ce n’est pas un mot de passe.
  8. Ne créez aucun secret client / certificat. Le CRM n’en veut pas.

Informatique E · Autoriser l’appli sur le site

Sans ça, Tester SharePoint dans le CRM dit « accès refusé ». Ouvrir Graph Explorer en admin SharePoint.

  1. Récupérer l’ID du site (remplacer cabinet et le chemin) : 
    GET https://graph.microsoft.com/v1.0/sites/cabinet.sharepoint.com:/sites/crm-patrimoine
    Copier le champ id (3 morceaux séparés par des virgules) → page 4.
  2. Donner le droit manage le temps que Tony crée les listes (coller le Client ID) : 
    POST https://graph.microsoft.com/v1.0/sites/{ID-DU-SITE}/permissions
{
  "roles": ["manage"],
  "grantedToIdentities": [{
    "application": { "id": "CLIENT-ID-DU-CRM", "displayName": "Patrimoine CRM" }
  }]
}
  3. Après que Tony a cliqué Provisionner listes CRM : supprimer ce droit manage, recréer le même avec "roles": ["write"]. Relancer Tester SharePoint. ☐ après H

Informatique F · Boîte e-mail du cabinet

admin.microsoft.com → Teams & groups → Shared mailboxes

  1. Créer la boîte (ex. cabinet@…). Ce n’est pas un compte pour ouvrir le CRM.
  2. Pour Tony et chaque assistante : Full Access + Send As. Pas « Send on behalf ».
  3. Attendre jusqu’à 1 h, puis tester un envoi. ☐ fait

Tony H · Allumer l’équipe sur votre PC

Fiche page 4 sous les yeux. Ne fermez pas le CRM pendant cette page.

  1. Paramètres → Intégrations → Mode équipe SharePoint.
  2. Coller le Client ID → Enregistrer Client ID. ☐
  3. Connecter Microsoft → votre compte pro (pas la boîte cabinet) → code MFA. ☐
  4. Activer le mode équipe. Rôle : Conseiller.
  5. Coller groupes, hostname, chemin, boîte → Enregistrer la configuration équipe. ☐
  6. Tester SharePoint → OK → Enregistrer la configuration équipe encore une fois (garde l’ID du site). ☐
  7. Provisionner listes CRM → attendre le OK. Cela crée aussi la clé de cache et masque CRM_Secrets. Ne rien créer dans SharePoint à la main. ☐
  8. Dire à l’informatique de passer le droit du site de manage à write (étape E.3), puis retester. ☐
  9. Copier la fiche pour une assistante (après le 2ᵉ enregistrement, l’ID site est dedans). Coller dans un e-mail interne ou imprimer. ☐
  10. Dans cet ordre, sans fermer :
    1. Préparer la migration
    2. Envoyer la copie test vers SharePoint
    3. Valider la restauration test
    4. Activer la synchronisation équipe
Pourquoi « migration » si le CRM est vide ? Le CRM a déjà posé tout seul quelques étiquettes et modèles d’e-mails. Ce n’est pas vos clients. Cette série allume l’équipe sur votre PC. Ne cliquez pas sur Rejoindre sur ce poste chez vous.
C’est bon chez vous quand l’espace équipe / cache est actif, sans bandeau rouge. Ensuite seulement : les assistantes.

Assistante I · Chaque PC (recommencer à zéro)

Uniquement après le OK de Tony. Un PC = une personne = son compte. Fiche page 4.

  1. Installer le CRM (même version que Tony). Créer le mot de passe local. Aucun import, aucun fichier copié. ☐
  2. Paramètres → Intégrations → Mode équipe SharePoint.
  3. Coller le Client ID → Enregistrer Client ID. ☐
  4. Connecter Microsoft → son e-mail pro → MFA. ☐
  5. L’adresse affichée doit être la sienne. Si c’est Tony ou la boîte cabinet : on arrête. ☐
  6. Activer le mode équipe. Rôle : Secrétaire.
  7. Coller toute la fiche, y compris l’ID du site, avant d’enregistrer. ☐
  8. Enregistrer la configuration équipe → Rejoindre sur ce poste. Les étiquettes et modèles d’e-mails posés tout seuls au 1er ouverture ne bloquent plus. Laisser ouvert. ☐
Si le CRM dit « ce poste contient déjà des données » — il y a de vrais contacts, dossiers ou investissements (un import, par exemple). Ne forcez pas. Prévenez Tony. Ne copiez aucun .db.
Après enregistrement en secrétaire, elle ne peut plus changer la config (groupes, site). Elle peut encore Connecter Microsoft si le compte expire, et Reconnecter le compte Microsoft à l’écran de verrouillage.
