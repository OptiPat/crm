Informatique A · Comptes Microsoft

Centre d’administration : admin.microsoft.com

  1. Créer ou vérifier 1 compte par personne (prénom.nom du cabinet), pas une boîte partagée :
    • Tony — e-mail :                     
    • Assistante 1 — e-mail :                   
    • Assistante 2 — e-mail :                   
  2. Chaque personne qui ouvre le CRM a une licence Microsoft 365 Business Basic (ou Standard, comme Tony). Ça donne SharePoint + messagerie. Pas Famille / Personal / « Premium » grand public (Hotmail). Pas Power Automate Free. La boîte d’envoi du cabinet (étape F) n’a pas besoin de licence.
  3. Activer le code à 2 facteurs sur les 3 comptes.
  4. Chacun se connecte une fois sur portal.office.com et valide le code. ☐ fait

Informatique B · Groupes Entra (les rôles)

Centre d’administration Microsoft Entra → Identité → Groupes → Tous les groupes

  1. Créer un groupe CRM - Conseillers (sécurité ou Microsoft 365 : les deux marchent). Y mettre uniquement le conseiller. Noter le nom exact et l’e-mail du groupe s’il y en a un.
  2. Ouvrir le groupe → copier l’ID d’objet (un long numéro) → le coller page 4.
  3. Créer un groupe CRM - Assistantes (même type). Y mettre uniquement les assistantes.
  4. Copier l’ID d’objet → le coller page 4.
  5. Vérifier : personne n’est dans les deux groupes. ☐ fait

Informatique C · Site SharePoint

  1. Créer un site rien que pour le CRM, par exemple :
    https://cabinet.sharepoint.com/sites/crm-patrimoine
  2. Tony = propriétaire du site. Les assistantes = membres.
  3. Noter (page 4) :
    • Nom d’hôte SharePoint = la partie avant /sites/ (ex. cabinet.sharepoint.com)
    • Chemin = ce qui commence par /sites/…
  4. Les 3 personnes ouvrent l’URL du site dans le navigateur. Ça doit marcher. ☐ fait
  5. Ne créez aucune liste à la main. Tony le fera dans le CRM.

Suite page suivante : application Entra, autorisation du site, boîte cabinet.

Informatique D · Application Entra « Patrimoine CRM »

Centre d’administration Microsoft Entra → Inscriptions d’applications → Nouvelle inscription

  1. Nom : Patrimoine CRM. Types de comptes : comptes dans cet annuaire d’organisation uniquement.
  2. Authentification → Ajouter une plateforme → Applications mobiles et de bureau.
  3. URI de redirection, exactement :
    http://127.0.0.1:3847/callback
  4. Autoriser les flux de client public = Oui.
  5. Autorisations de l’API → Microsoft Graph → Autorisations déléguées, ajouter pile ceci (laisser ces noms techniques tels quels) :
    • User.Read
    • GroupMember.Read.All
    • Sites.Selected
    • Mail.Send.Shared
    • offline_access
    • openid
    • email
  6. Bouton Accorder le consentement administrateur. ☐ fait
  7. Toujours dans Autorisations de l’API → SharePoint (Office 365 SharePoint Online) → Autorisations déléguées → ajouter AllSites.Manage. Accorder le consentement administrateur une 2ᵉ fois. Sans ça, Provisionner échoue (401). Ne pas ajouter AllSites.FullControl sur cette appli. ☐ fait
  8. Copier l’ID d’application (client) → page 4. Ce n’est pas un mot de passe.
  9. Ne créez aucun secret client / certificat. Le CRM n’en veut pas.

Informatique E · Autoriser l’appli sur le site

Sans ça, le bouton Tester SharePoint dans le CRM dit « accès refusé ». Ouvrir l’Explorateur Graph avec un compte administrateur SharePoint. Ne pas coller les accolades { } : Graph Explorer les affiche comme aide, l’URL réelle n’en contient pas.

  1. Récupérer l’ID du site (remplacer le nom du cabinet et le chemin) : 
    GET https://graph.microsoft.com/v1.0/sites/cabinet.sharepoint.com:/sites/crm-patrimoine
    Copier le champ id (3 morceaux séparés par des virgules) → page 4.
  2. Donner le droit de gestion le temps que Tony crée les listes. Remplacer ID-DU-SITE par les 3 morceaux (virgules), sans accolades, et coller l’ID d’application : 
    POST https://graph.microsoft.com/v1.0/sites/ID-DU-SITE/permissions
{
  "roles": ["manage"],
  "grantedToIdentities": [{
    "application": { "id": "CLIENT-ID-DU-CRM", "displayName": "Patrimoine CRM" }
  }]
}
    Laisser manage (pas fullcontrol : CRM 0.5.38 n’en a pas besoin). C’est le mot attendu par Microsoft.
  3. Après que Tony a cliqué Provisionner listes CRM : supprimer ce droit de gestion, recréer le même avec "roles": ["write"] (écriture). Relancer Tester SharePoint. ☐ après H

Informatique F · Boîte e-mail du cabinet

admin.microsoft.com → Équipes et groupes → Boîtes aux lettres partagées

  1. Créer une boîte partagée (ex. cabinet@… ou office@…). Aucune licence Microsoft à payer en plus. Ce n’est pas un compte pour ouvrir le CRM, ni pour le 2ᵉ PC.
  2. Pour Tony et chaque assistante : Accès total + Envoyer en tant que. Pas « Envoyer de la part de ».
  3. Attendre jusqu’à 1 h, puis tester un envoi. ☐ fait

Tony H · Allumer l’équipe sur votre PC

CRM 0.5.38 ou plus (Paramètres → À propos). En dessous : installer, puis Déconnecter / Connecter Microsoft. Fiche page 4 sous les yeux. Ne fermez pas le CRM pendant cette page.

  1. Paramètres → Intégrations → Mode équipe SharePoint.
  2. Coller le Client ID → Enregistrer Client ID. ☐
  3. Connecter Microsoft → votre compte professionnel du cabinet (pas un compte Outlook.com / Hotmail, pas la boîte cabinet) → code à 2 facteurs. Le bandeau beige « identité nominative » disparaît une fois connecté (ce n’était pas une erreur). ☐
  4. Passez l’interrupteur Activer le mode équipe SharePoint (à droite). Dans Rôle sur cette installation, choisissez Conseiller. Ce n’est pas le bouton Activer la synchronisation équipe (plus tard). ☐
  5. Coller les groupes, le nom d’hôte, le chemin, la boîte → Enregistrer la configuration équipe. ☐
  6. Tester SharePoint → OK → Enregistrer la configuration équipe encore une fois (garde l’ID du site). ☐
  7. Provisionner listes CRM → attendre le OK. CRM 0.5.38 ou plus. Cela crée les listes, écrit la clé de cache et masque CRM_Secrets. Un message 403 sur les droits de la liste n’arrête plus Provisionner : la clé s’écrit quand même. Ne rien créer dans SharePoint à la main. N’ouvrez pas CRM_Secrets. ☐
  8. Dire à l’informatique de passer le droit du site de gestion (manage) à écriture (write) (étape E.3), puis retester. ☐
  9. Copier la fiche pour une assistante (après le 2ᵉ enregistrement, l’ID site est dedans — le bouton reste gris tant que l’ID est vide). Coller dans un e-mail interne ou imprimer. ☐
  10. Chez vous, ne cliquez pas sur Rejoindre sur ce poste (c’est pour un PC vide). Dans cet ordre :
    1. Préparer la migration
    2. Envoyer la copie test vers SharePoint
    3. Valider la restauration test
    4. Activer la synchronisation équipe
    Une fois l’équipe allumée, ces boutons disparaissent. Ne les recliquez jamais « pour voir ».
Pourquoi « migration » si le CRM est vide ? Le CRM a déjà posé tout seul quelques étiquettes et modèles d’e-mails. Ce n’est pas vos clients. Cette série allume l’équipe sur votre PC. Ne cliquez pas sur Rejoindre sur ce poste chez vous.
C’est bon chez vous quand l’espace équipe / cache est actif, sans bandeau d’erreur (ambre). Ensuite seulement : les assistantes.

Assistante I · Chaque PC (recommencer à zéro)

Uniquement après le OK de Tony. Un PC = une personne = son compte. CRM 0.5.43 (comme chez vous). Imprimez-leur GUIDE_ASSISTANTE (2 pages), pas ce document. Fiche copiée depuis le CRM sous les yeux.

  1. Installer le CRM (même version que Tony, 0.5.43, en bas à gauche). Créer le mot de passe local. Aucun import, aucun fichier copié. Assistant : Vos informations → Terminer. ☐
  2. Paramètres → Intégrations → Mode équipe SharePoint.
  3. Coller le Client ID → Enregistrer Client ID. ☐
  4. Connecter Microsoft → son e-mail professionnel → code à 2 facteurs. ☐
  5. L’adresse affichée doit être la sienne. Si c’est Tony ou la boîte cabinet : on arrête. ☐
  6. Passez l’interrupteur Activer le mode équipe SharePoint. Dans Rôle sur cette installation, choisissez Secrétaire.
  7. Recopier chaque ligne de la fiche dans le champ du même usage (pas tout dans une case). L’ID site Graph est obligatoire malgré « optionnel ». Avant d’enregistrer. ☐
  8. Enregistrer la configuration équipe → Rejoindre sur ce poste. Les étiquettes et modèles d’e-mails posés tout seuls au 1er ouverture ne bloquent plus. Laisser ouvert. ☐
Si le CRM dit « ce poste contient déjà des données » — il y a de vrais contacts, dossiers ou investissements (un import, par exemple). Ne forcez pas. Prévenez Tony. Ne copiez aucun .db.
Après enregistrement en secrétaire, elle ne peut plus changer la config (groupes, site). Elle peut encore Connecter Microsoft si le compte expire, et Reconnecter le compte Microsoft à l’écran de verrouillage.
